# Titanic-Cleaning-Pipeline

This project cleans and standardizes a raw Titanic passenger dataset, handles missing or malformed values, and generates a survival report broken down by passenger class, gender, and age group.

## What the pipeline does

- Normalizes inconsistent raw data into a cleaner, analysis-ready structure
- Handles missing and malformed passenger fields in a consistent way
- Produces survival summaries segmented by:
  - Passenger class
  - Gender
  - Age group

## Typical workflow

1. Load the raw Titanic passenger dataset
2. Apply cleaning and normalization rules
3. Validate and standardize key fields
4. Generate grouped survival statistics for reporting

## Output focus

The final report is designed to make survival trends easier to compare across major passenger demographics.
